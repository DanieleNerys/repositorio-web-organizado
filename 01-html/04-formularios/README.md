# Exemplo 04 — Formulários HTML
**Objetivo:** criar campos e associar rótulos usando `label`.

**O que acontece:** formulário demonstrativo com nome, e-mail e área. `required` e `type=email` ativam validações do navegador.

**Executar:** abra `index.html` e teste o envio. Nenhum dado é enviado ao servidor.

**Pratique:** adicione data de nascimento ou um campo de observações.
