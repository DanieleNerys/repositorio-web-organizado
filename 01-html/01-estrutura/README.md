# Exemplo 01 — Estrutura HTML
**Objetivo:** conhecer o esqueleto mínimo de um documento HTML5.

**O que acontece:** `head` guarda metadados e título; `body` contém o conteúdo. São usados `header`, `main`, `section` e `footer`.

**Executar:** abra `index.html` no navegador.

**Pratique:** troque o título e acrescente uma nova seção.
