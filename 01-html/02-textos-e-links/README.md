# Exemplo 02 — Textos e links
**Objetivo:** praticar títulos, parágrafos, negrito, ênfase e hiperlinks.

**O que acontece:** a página usa `h1`, `h2`, `p`, `strong`, `em` e links internos e externos.

**Executar:** abra `index.html`.

**Pratique:** crie um link para outra página sua e escreva um texto de link descritivo.
