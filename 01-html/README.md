# 01 — HTML5
HTML define a estrutura e o significado do conteúdo.

- `01-estrutura`: esqueleto HTML5 e elementos semânticos.
- `02-textos-e-links`: títulos, parágrafos, ênfase e hiperlinks.
- `03-listas-e-tabelas`: listas e tabelas acessíveis.
- `04-formularios`: campos, rótulos e validação nativa.

Abra cada `index.html` no navegador. Pratique alterando textos e acrescentando elementos semânticos como `header`, `main`, `section` e `footer`.
