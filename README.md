# Repositório de Estudos — Desenvolvimento Web

Projeto didático dividido por tecnologia e assunto. Cada pasta e cada exemplo possuem README explicando o objetivo, o código e como executar.

## Estrutura

- `01-html/`: estrutura, textos e links, listas e tabelas, formulários.
- `02-css/`: seletores e cores, box model, Flexbox, Grid e responsividade.
- `03-javascript/`: variáveis e funções, condicionais e repetição, DOM e eventos, lista de tarefas.
- `04-php/`: primeiros passos, condicionais e loops, formulários, includes.

## Como executar

HTML/CSS: abra os arquivos `index.html` no navegador.
JavaScript: abra os exemplos no navegador; F12 > Console permite ver mensagens.
PHP: instale PHP 8+, abra o terminal na raiz e execute `php -S localhost:8000`. Acesse os endereços indicados nos READMEs PHP. Não abra PHP por `file://`.

Os formulários são demonstrações: não armazenam dados em banco nem enviam e-mails. Use dados fictícios.
