# Exemplo 01 — Variáveis e funções
**Objetivo:** declarar variáveis e criar uma função reutilizável.

**O que acontece:** a função soma dois números e o botão mostra o resultado na página.

**Executar:** abra `index.html` e clique no botão.

**Pratique:** altere os valores de `numeroA` e `numeroB` em `script.js`.
