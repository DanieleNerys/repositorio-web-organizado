# Exemplo 04 — Lista de tarefas
**Objetivo:** combinar formulário, DOM, eventos e criação/remoção de elementos.

**O que acontece:** digite uma tarefa para adicioná-la à lista e use Remover para excluí-la. Os dados ficam na memória da página e são perdidos ao atualizar.

**Executar:** abra `index.html`.

**Pratique:** implemente uma opção para marcar tarefas como concluídas.
