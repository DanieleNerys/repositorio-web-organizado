# Exemplo 03 — DOM e eventos
**Objetivo:** alterar conteúdo e aparência após uma ação do usuário.

**O que acontece:** o botão alterna uma classe CSS e atualiza o texto. São usados `querySelector`, `addEventListener` e `classList.toggle`.

**Executar:** abra `index.html` e clique no botão.

**Pratique:** crie outro botão para mudar o texto.
