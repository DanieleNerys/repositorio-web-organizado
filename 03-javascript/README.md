# 03 — JavaScript
JavaScript adiciona lógica e interatividade às páginas.

- `01-variaveis-e-funcoes`: variáveis, funções e retorno.
- `02-condicionais-e-repeticao`: `if/else` e laço `for`.
- `03-dom-e-eventos`: manipulação do DOM e clique.
- `04-lista-de-tarefas`: mini aplicação para adicionar e remover tarefas.

Abra os `index.html` no navegador. Para ver `console.log`, use F12 > Console.
