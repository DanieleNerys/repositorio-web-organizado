# Exemplo 02 — Condicionais e repetição
**Objetivo:** praticar `if/else` e `for`.

**O que acontece:** a pessoa informa uma nota; o programa valida o intervalo de 0 a 10 e verifica média 7. Um laço gera a contagem de 1 a 5.

**Executar:** abra `index.html` e informe uma nota.

**Pratique:** mude a média mínima para 6.
