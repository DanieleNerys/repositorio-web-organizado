# 04 — PHP
PHP é executado no servidor. O navegador recebe o HTML gerado, não o código PHP original.

- `01-primeiros-passos`: variáveis, `echo` e data dinâmica.
- `02-condicionais-e-loops`: decisões e `foreach`.
- `03-formularios`: recebimento e validação de POST.
- `04-includes`: reutilização de cabeçalho e rodapé.

## Executar
Instale PHP 8+. No terminal, na raiz do repositório, execute `php -S localhost:8000`. Acesse, por exemplo, `http://localhost:8000/04-php/01-primeiros-passos/`.

Não abra arquivos PHP por `file://`. Os exemplos não usam banco de dados e não enviam e-mails. Use apenas dados fictícios.
