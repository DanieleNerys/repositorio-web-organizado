# Exemplo 03 — Formulário com PHP
**Objetivo:** receber dados via POST e validá-los no servidor.

**O que acontece:** `index.php` exibe o formulário; `processa.php` valida nome e e-mail e apresenta o resultado com saída escapada.

**Executar:** inicie o servidor na raiz e acesse `/04-php/03-formularios/`.

**Pratique:** adicione um campo mensagem e valide o tamanho no PHP.

**Atenção:** este exemplo não salva dados nem envia e-mail. Use informações fictícias.
