# Exemplo 01 — Primeiros passos com PHP
**Objetivo:** gerar conteúdo no servidor.

**O que acontece:** variáveis são exibidas com `echo`/`<?= ?>` e `date()` apresenta data e hora do servidor. `htmlspecialchars` protege a saída textual.

**Executar:** inicie o servidor na raiz e acesse `/04-php/01-primeiros-passos/`.

**Pratique:** crie uma variável com o nome de uma disciplina e exiba-a.
