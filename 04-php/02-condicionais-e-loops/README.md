# Exemplo 02 — Condicionais e loops
**Objetivo:** praticar `if/else` e `foreach` no PHP.

**O que acontece:** uma nota é avaliada e um array de tecnologias é percorrido para gerar itens HTML.

**Executar:** inicie o servidor na raiz e acesse `/04-php/02-condicionais-e-loops/`.

**Pratique:** acrescente uma tecnologia ao array e teste outras notas.
