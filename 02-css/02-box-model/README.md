# Exemplo 02 — Box model
**Objetivo:** entender conteúdo, padding, borda e margem.

**O que acontece:** duas caixas demonstram os espaços internos e externos. `box-sizing: border-box` simplifica o cálculo de dimensões.

**Executar:** abra `index.html`.

**Pratique:** aumente o `padding` e compare o tamanho visual.
