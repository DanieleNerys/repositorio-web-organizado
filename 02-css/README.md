# 02 — CSS3
CSS controla cores, fontes, espaçamentos, alinhamento e adaptação a telas.

- `01-seletores-e-cores`: seletores de elemento, classe e ID.
- `02-box-model`: conteúdo, padding, borda e margem.
- `03-flexbox`: alinhamento e distribuição em uma dimensão.
- `04-grid-e-responsividade`: grade e media queries.

Abra cada `index.html`; os estilos estão no `style.css` correspondente. Altere uma propriedade por vez e atualize o navegador.
