# Exemplo 04 — Grid e responsividade
**Objetivo:** criar uma grade que se adapta à largura da tela.

**O que acontece:** CSS Grid cria quatro colunas; media queries reduzem para duas e depois uma coluna.

**Executar:** abra `index.html` e redimensione a janela.

**Pratique:** altere o breakpoint de 800px.
